# Bitcoin Books - Academic Publishing & Library Management Platform

Bitcoin Books is a comprehensive academic publishing and library management system built on the solid foundation of Koha ILS. Our platform combines traditional library science with blockchain technology to create a transparent, peer-reviewed academic ecosystem.

## About Bitcoin Books

Built for academics, researchers, and institutions who value:
- **Transparent peer review processes**
- **Academic reputation systems** 
- **Tokenized research incentives**
- **Regulatory-compliant publishing**
- **Traditional library management excellence**

## Core Features

### Library Management (Koha Foundation)
- Cataloging and circulation
- MARC record management
- User management and permissions
- Reports and analytics
- Multi-language support

### Academic Workflow Extensions
- Peer review management
- Academic reputation tracking
- Research collaboration tools
- Publication lifecycle management

### Blockchain Integration (BSV)
- Tokenized research outputs
- Smart contract automation
- Transparent funding mechanisms
- Immutable academic records

## Technology Stack

- **Backend**: Perl, MySQL/MariaDB
- **Frontend**: HTML5, CSS3, JavaScript
- **Server**: Apache HTTP Server
- **Blockchain**: Bitcoin SV (BSV)
- **License**: GNU GPL v3
